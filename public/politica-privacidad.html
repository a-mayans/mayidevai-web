2. Datos personales tratados

MayidevAI puede tratar los siguientes tipos de datos personales, en función de la interacción del usuario con el sitio web:

  • Datos identificativos: nombre y apellidos.
  • Datos de contacto: correo electrónico y teléfono.
  • Datos profesionales: empresa, cargo o sector.
  • Información facilitada mediante formularios de contacto o comunicaciones directas.
  • Datos técnicos mínimos necesarios para la comunicación, como dirección IP o navegador.

Este sitio web no utiliza cookies ni tecnologías de seguimiento, ni realiza análisis del comportamiento de los usuarios mediante herramientas de analítica web.

No se tratan datos especialmente protegidos.

3. Finalidad del tratamiento

Los datos personales se tratan con las siguientes finalidades:

  • Responder a solicitudes de contacto o información.
  • Gestionar presupuestos y relaciones profesionales o comerciales.
  • Prestar servicios de automatización de procesos y consultoría en inteligencia artificial.
  • Gestionar reuniones, agendas y comunicaciones profesionales.
  • Cumplir obligaciones legales, fiscales y contractuales.

Los datos no se utilizarán para finalidades distintas sin informar previamente al usuario.

4. Base legal del tratamiento

La base legal para el tratamiento de los datos personales es:

  • El consentimiento expreso del usuario al enviar formularios o contactar.
  • La aplicación de medidas precontractuales cuando el usuario solicita información sobre servicios.
  • La ejecución de un contrato, cuando exista relación profesional o comercial.
  • El cumplimiento de obligaciones legales aplicables.
  • El interés legítimo del responsable para la gestión profesional del negocio, cuando proceda.

5. Conservación de los datos

Los datos personales se conservarán mientras exista una relación profesional o comercial y, posteriormente, durante los plazos legalmente exigidos para el cumplimiento de obligaciones fiscales, legales y administrativas.

El usuario podrá solicitar la supresión de sus datos cuando proceda legalmente.

6. Destinatarios de los datos

Los datos podrán ser tratados por proveedores tecnológicos necesarios para la prestación del servicio, actuando como encargados del tratamiento, tales como:

  • Servicios de alojamiento web y servidores.
  • Plataformas de automatización de procesos.
  • Proveedores de correo electrónico y agenda.
  • Servicios de almacenamiento en la nube.
  • APIs y servicios de inteligencia artificial utilizados en automatizaciones.

No se cederán datos a terceros salvo obligación legal.
